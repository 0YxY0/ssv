# T5 CI 依赖补齐 plan

## 实施步骤

1. 检查 PR #15 的 GitHub Actions 失败日志，确认失败点来自 CI 环境依赖缺失。
2. 在 `.github/workflows/ci.yml` 的系统依赖中加入 `ripgrep`。
3. 在 `.github/workflows/ci.yml` 的 Python tooling 安装步骤中加入 `PyYAML`，使用 `actions/setup-python` 提供的解释器安装。
4. 运行 shell 语法检查和本地测试入口，确认改动不会影响现有测试编排。

## 风险控制

- 仅修改 CI 依赖安装，不改变脚本行为和运行时配置读取逻辑。
- `PyYAML` 安装在 setup-python 解释器中，避免 `apt` 安装包与 CI 当前 `python3` 不一致。
- `ripgrep` 使用 Ubuntu 官方包，匹配 `tests/ssv_cli_test.sh` 已有命令依赖。
