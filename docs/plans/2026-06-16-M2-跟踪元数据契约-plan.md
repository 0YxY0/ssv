# M2 跟踪元数据契约 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `M2/B` tracking metadata contract by:
1. Extending `SsvDetection` with `track_state` (NEW/MATCHED/LOST/DEAD) and `occluded` flag.
2. Making `track-thresh` property effective in IoU tracker for occlusion detection.
3. Adding tracking-specific tests to `gst/tests/test_ssv_meta.cpp`.
4. Adding `track_id`, state, and occlusion info to `gst/ssv-overlay/gstssvoverlay.cpp`.
5. Publishing `track_state` and `occluded` in `ssvpub` Redis detection JSON.

**Architecture:** The contract lives at the `SsvDetectionStore` boundary. `ssvtrack` writes `track_id`, `track_state`, and `occluded` into each `SsvDetection`. The `M1/B` normalization at `SsvDetectionStore::set()` / `set_tracked()` also normalizes `track_state` to valid range. `ssvpub` and `ssvoverlay` read these fields unchanged.

**Tech Stack:** C++17, GStreamer plugin shared code, Meson, `gst/tests`, shell entrypoint `./ssv`.

## Task 1: Extend Detection Struct with Tracking Fields

**Files:**
- Modify: `gst/ssv-common/include/ssv_meta.hpp`

- [ ] **Step 1: Add `SsvTrackState` enum before `SsvDetection`**

```cpp
/// Track state enum — 2-bit, embedded in SsvDetection::track_state.
///
///  - NEW (0):   Track just created in this frame (first appearance).
///  - MATCHED (1): Track successfully matched to an existing trajectory.
///  - LOST (2):   Track alive but unmatched this frame (time_since_seen > 0).
///                No corresponding detection exists in current frame output.
///  - DEAD (3):   Track exceeded track-buffer and was removed.
///                No corresponding detection exists.
enum SsvTrackState : int {
    SSV_TRACK_NEW = 0,
    SSV_TRACK_MATCHED = 1,
    SSV_TRACK_LOST = 2,
    SSV_TRACK_DEAD = 3,
};
```

- [ ] **Step 2: Add `track_state` and `occluded` to `SsvDetection`**

```cpp
struct SsvDetection {
    char class_name[32];   ///< Short label name, e.g. "person"
    float confidence;      ///< finite [0, 1]
    float x1, y1, x2, y2; ///< original-frame normalized bbox, [0, 1], left-top/right-bottom
    int class_id = -1;     ///< model class index, -1 = unset
    int track_id = -1;     ///< assigned by ssvtrack, -1 = not tracked
    int track_state = SSV_TRACK_NEW;  ///< SsvTrackState for this detection's track
    bool occluded = false; ///< true when confidence < track-thresh on a matched track
};
```
