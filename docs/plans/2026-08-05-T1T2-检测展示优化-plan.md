# T1/T2 检测展示优化实施计划

## 实施顺序

本计划已完成，按以下依赖顺序组织实现和验证：

1. 固定 source-scoped metadata、timing 和 generation 契约；
2. 将 detection mailbox、tracked publication 与 PTS history 接入 infer、track、pub；
3. 抽取 overlay predictor、presentation、runtime 和 renderer；
4. 将 latest-frame、显示节流、解码器选择和 GTK backend 接入 runner；
5. 用自动化测试覆盖候选选择、预测窗口、GPU/CPU 内存边界和回退错误。

## 实施落点

### 1. Common timing and metadata

- gst/ssv-common/include/ssv_meta.hpp
- gst/ssv-common/frame/ssv_analysis_frame.cpp
- gst/ssv-common/meta/ssv_meta.cpp
- gst/ssv-common/tests/test_ssv_meta*.cpp
- gst/ssv-common/tests/test_ssv_analysis_frame.cpp

SsvFrameTiming、SsvTimelineCursor、SsvSourceContext 和 immutable SsvTrackedFrame 是唯一跨插件
展示契约。analysis frame 只允许一次受控映射，并保留 source/model transform。

### 2. Inference, tracking and publication

- gst/ssv-infer/core/ssv_inference_service.cpp
- gst/ssv-track/plugin/gstssvtrack.cpp
- gst/ssv-track/adapters/ssv_track_adapter.cpp
- gst/ssv-pub/gstssvpub.cpp

推理结果带有原始 frame timing；track adapter 完成坐标和 GMC 转换；pub 只消费 tracked
publication，不读取 overlay prediction。

### 3. Overlay display

- gst/ssv-overlay/overlay_motion_predictor.*
- gst/ssv-overlay/overlay_presentation.*
- gst/ssv-overlay/overlay_runtime.*
- gst/ssv-overlay/overlay_renderer.*
- gst/ssv-overlay/gstssvoverlay.cpp

OverlayPresentation 先按 source/generation/PTS 选择因果 snapshot，再把预测结果包装为
SsvOverlayFrame。renderer 只绘制 frame，不持有 tracker 或 inference 生命周期。

### 4. Runner display and pipeline

- runner/display/ssv_display_window.*
- runner/pipeline/ssv_pipeline_plan.cpp
- runner/pipeline/ssv_pipeline_builder.cpp
- runner/runtime/ssv_run_attempt_factory.cpp
- config/ssv.example.yaml

显示分支和分析分支分别设置 drop-only rate。GPU decode、GL sink、CPU overlay 和软件回退的
组合由 SsvPipelinePlan 决定，不能由 shell 字符串拼接隐式改变。

## 验证

    meson test -C build --print-errorlogs
    bash tests/ssv_cli_test.sh
    bash tests/ssv_deps_test.sh

验收重点：

- 显示 PTS 不会消费未来 detection；
- generation reset 后不会复用旧 tracked snapshot；
- 预测超出 horizon 后停止；
- 显式 nvdec、vaapi 或 GL backend 不可用时返回明确错误；
- gtksink 兼容路径不要求 DMABuf export；
- overlay 绘制不会改变发布 payload。
